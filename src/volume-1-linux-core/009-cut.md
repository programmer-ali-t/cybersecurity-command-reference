## FUNCTION

**Purpose.** Extract fields or character ranges from line-oriented structured text.

**Formal definition.** `cut` splits each line by a single-character delimiter (`-d`) and prints selected fields (`-f`), or prints byte/character ranges (`-b`/`-c`). It is strictly single-character delimiter — no regex, no CSV quoting. Lines lacking the delimiter pass through unchanged unless `-s` is given.

**When to use.**

- Extract columns from simple delimited output.
- Pull fields from `/etc/passwd` or `ps` output.
- Feed structured downstream tools (`sort`, `uniq`, `awk`).

**When NOT to use.**

- CSV with quoted fields. Use `csvcut`, `mlr`, or a Python one-liner.
- Regex-based splitting. Use `awk` or `sed`.
- Multi-character delimiters. Use `awk -F`.

**Preferred alternatives.**

| Situation | Better tool |
|---|---|
| CSV | `csvcut`, `mlr`, `python3 -c 'import csv...'` |
| Regex delimiter | `awk -F'regex'` |
| JSON | `jq` |
| Reorder fields | `awk '{print $3,$1}'` |

## SYNTAX

**Canonical form.**

```text
cut -d<delim> -f<fields> [FILE]
cut -c<range> [FILE]
```

**Curated options.**

| Option | Meaning |
|---|---|
| `-d X` | Delimiter character X (single char only) |
| `-f N` | Field N (comma-separated ranges: `1,3-5`) |
| `-c N-M` | Characters N to M |
| `-b N` | Bytes |
| `--complement` | Invert field selection |
| `-s` | Only lines containing the delimiter |
| `--output-delimiter=STR` | Replace output delimiter |

**Dangerous options.** None. `cut` is read-only.

**Deprecated / changed.**

| Old | Current | Note |
|---|---|---|
| `-d 'TAB'` | `-d $'\t'` | Bash ANSI-C quoting needed for tab |

## APPLICATION

**Minimal example.**

```bash
cut -d: -f1 /etc/passwd
```

**Realistic example — usernames and shells, aligned.**

```bash
cut -d: -f1,7 /etc/passwd | column -t -s:
```

**Expected output.**

```text
root      /bin/bash
daemon    /usr/sbin/nologin
bin       /usr/sbin/nologin
sys       /usr/sbin/nologin
```

**Interpretation.**

- Field numbering starts at 1.
- `-f2-` means "field 2 to end."
- `-f1,3,5` selects non-contiguous fields.
- Lines without the delimiter appear verbatim unless `-s`.
- `-c` counts characters, `-b` counts bytes; on UTF-8 they differ.

**Common misreadings.**

| Misreading | Reality |
|---|---|
| `cut` handles quoted CSV | It does not; quoted commas break field counting |
| Multi-char delimiter supported | Only single character |
| Fields can be reordered | Order is always source order; use `awk` to reorder |
| `cut -c` is byte-safe on UTF-8 | It is character-based; `-b` for bytes |

## OPERATIONAL

**Privilege required.** None.

**Failure modes.**

| Failure | Cause | Fix |
|---|---|---|
| `cut: the delimiter must be a single character` | Passed a string or empty value | Use `awk -F` or pass one char |
| Output shifted on quoted input | CSV quoting ignored | Use `csvcut` |
| Empty output on lines without delimiter | Missing `-s` flag in reverse | Add or remove `-s` as needed |

**Blast radius.** None.

**Recovery path.** Not applicable.

**Performance impact.** Streaming, O(n). Fast. Handles multi-GB files linearly.

## EDUCATIONAL

**Learning objective.** Choose between `cut`, `awk`, and `sed` for text extraction, and explain when `cut` silently corrupts CSV data.

**Prerequisites.** Understanding of delimiters, quoting in CSV, and field-based processing.

**Guided exercise (15 min).**

Extract fields 1 and 5 from `/etc/passwd`. Then use `awk -F: '{print $1,$5}'`. Compare output. Now create a CSV with a quoted comma inside a field and show `cut` failing.

**Challenge (45 min).**

Write a shell script that safely extracts the 3rd field from a file that may contain quoted commas. Explain why `cut` is unsuitable and how you validated your approach.

**Quiz.**

1. Why does `cut` fail on quoted CSV?
2. What does `--complement` do?
3. When does `-c` differ from `-b`?
4. How do you specify a tab as delimiter in bash?

**Real-world story.**

A SOC pipeline used `cut -d, -f3` on logs that sometimes contained quoted commas. Alert severity values were occasionally shifted. Postmortem: replace `cut` with `awk -F,` and validation. Delimiters matter.
